Bank2Tally Features

Everything you need to go from raw bank statement to Tally-ready vouchers.

Import

  • PDF bank statements, including scanned/image PDFs via OCR
  • Excel (.xls/.xlsx) statement exports
  • CSV statement files

Processing

  • Automatic column detection and mapping (date, narration, debit, credit, balance)
  • Automatic ledger matching against your existing Tally ledgers
  • Auto-creation of new party ledgers when no match is found
  • Duplicate transaction detection before import
  • Voucher type classification: Receipt, Payment, Contra

Export

  • Tally XML export, compatible with Tally Prime and Tally ERP 9
  • Direct push to Tally via the Tally Gateway (when the Bank2Tally extension is installed)
  • Import history stored locally for quick re-import

Coverage

Supports statement formats from HDFC, ICICI, SBI, Axis, Kotak, PNB, Bank of Baroda, Bank of India, Central Bank, Federal Bank, IOB and other major Indian banks. See bank-specific guides.

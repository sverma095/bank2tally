How to Import a Bank Statement in Tally Prime

Tally Prime supports native bank statement import via Gateway of Tally > Alt+O (Import) > Bank Statement, but it requires a properly formatted file matching your bank's template. Bank2Tally prepares that file for you automatically, whatever format your bank statement is in.

Step-by-step with Bank2Tally

  1. Upload your bank statement (PDF, scanned PDF, Excel or CSV) to Bank2Tally.
  2. Review auto-mapped ledgers and correct any that need manual mapping.
  3. Check flagged duplicate transactions.
  4. Export as Tally XML.
  5. In Tally Prime: Gateway of Tally > Alt+O (Import) > Bank Statement > select the exported file > Import.

Common import errors this avoids

  • "Not a valid format" errors from mismatched column structure.
  • Duplicate voucher entries from re-imported statement ranges.
  • Missing ledgers for new parties — auto-created during mapping.
